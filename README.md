# Body Log

A private journal for sleep, food, water, toilet, symptoms, mood, thoughts and daily activity.
Installable PWA. Works offline. All data stays on your phone.

## Put it on GitHub Pages

1. Create a new GitHub repository (public is fine, it holds no data).
2. Upload every file from this folder to the repository root.
3. Open Settings, then Pages. Under Build and deployment choose "Deploy from a branch", pick `main` and `/ (root)`, then Save.
4. After a minute your app is live at `https://<your-username>.github.io/<repo-name>/`.
5. Open that link on your phone and use "Add to Home screen" or "Install app".

## Update later

Upload the changed files over the old ones. The app picks up the new version the next time it opens online.

## Your data

Entries live in the browser storage of the phone you use. Clearing browser data deletes them,
so keep the daily backup files, and use Export CSV or PDF from the menu at the top right.
